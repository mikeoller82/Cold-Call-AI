# ❄️ Cold-Call-AI

**Generate personalized, high-converting cold call scripts using AI.**

This project uses Google’s AI (via a free API key) to create customized, ready-to-use cold call scripts for sales outreach — built for anyone who wants better call performance with less manual writing.

---

## 🚀 Features

- 📞 Generates cold call scripts based on your parameters  
- ⚡ Fast, automated AI-powered content generation  
- 🆓 Uses free tier Google API keys (enough for ongoing use)  
- 💡 Open source — extend and customize however you like

---

## 🧠 How It Works

This app runs locally or in a development environment and uses Google’s AI API to produce cold call scripts from input prompts you provide. It’s perfect for sales teams, solo founders, and anyone doing outreach who wants to *stop writing scripts by hand*.

---

## 📦 Getting Started

### 1. **Prerequisites**
Make sure you have:

- Node.js installed  
- A free Google API key from Google AI Studio

---

### 2. **Clone the Repo**

```bash
git clone https://github.com/mikeoller82/Cold-Call-AI.git
cd Cold-Call-AI
````

---

### 3. **Install Dependencies**

```bash
npm install
```

---

### 4. **Configure Your API Key**

Create a `.env.local` file in the root of the project and add:

```env
GEMINI_API_KEY=YOUR_GOOGLE_API_KEY_HERE
```

> You can get a free API key from **Google AI Studio** — they give you plenty of free usage for this app unless you intentionally push it beyond normal use.

---

### 5. **Run Locally**

```bash
npm run dev
```

Once it’s running, open the app in your browser and start generating scripts.

---

## 📝 Example Usage

Enter a company or product name + context, and the AI will return a *ready-to-use cold call script* tailored to your needs.
